# تطبيق الموظفين Wavixa CRM Mobile App (React Native / Expo)

تطبيق موبايل متكامل واحترافي مخصص لموظفي خدمة العملاء (Agents) ومديري النظام لنظام **Wavixa CRM**.
تم تصميم التطبيق وفقاً لأعلى معايير الـ UI/UX المستوحاة بدقة من **تجربة WhatsApp** مع هوية **Wavixa** البصرية، وبأحجام مضغوطة ومتناسقة ومريحة جداً لعين المستخدم.

---

## 📱 مميزات التطبيق

### 1. شاشة تسجيل الدخول والترحيب (Login & Welcome)
- تسجيل دخول مباشر للموظفين (مثل `crm@crm.com` وجميع الموظفين المضافين من لوحة `/crm/agents`).
- حقول إدخال آمنة وسلسة مع إمكانية إظهار/إخفاء كلمة المرور.
- **شاشة ترحيبية أنيقة (Welcome Screen)** ترحب بالموظف باسمه وتستعرض دوره ومجموعته وطاقة العمل المسموحة له وتنقله تلقائياً إلى قائمة المحادثات.

### 2. شاشة المحادثات الرئيسية (Chat List Screen)
- **الهيدر المضغوط**: لوجو Wavixa CRM الأيقوني، زر القائمة (⋮)، وصورة الموظف الدائرية مع مؤشر الحالة الأونلاين وعداد المحادثات النشطة.
- **شريط البحث (Search Bar)**: بحث سريع ومريح في أسماء وأرقام ونصوص رسائل العملاء.
- **شريط الفلاتر (Filter Chips)**: تبويبات سريعة دائرية (الكل، غير مقروءة مع بادج رقمي، محادثاتي الخاصة، جديد/متاح، المجموعات، المكتملة، المؤرشفة).
- **بطاقات المحادثات (Chat Items)**:
  - صورة العميل الرمزية مع علامة المنصة (واتساب 🟢).
  - اسم العميل ورقم هاتفه.
  - نص آخر رسالة مع إشارات القراءة (✓ / ✓✓ زرقاء).
  - وقت الرسالة وبادج عدد الرسائل غير المقروءة أو علامة التثبيت 📌.
  - بادج اسم الموظف المستلم أو جهاز الواتساب.
- **شريط التنقل السفلي المدمج (Bottom Navigation)**:
  - المحادثات (Chats)
  - الفلاتر (Filters)
  - الزر العائم في المنتصف (Floating Action Button) لبدء محادثة جديدة لرقم هاتف فوراً
  - الإحصائيات (Stats)
  - الإعدادات والملف الشخصي (Settings)

### 3. شاشة المحادثة والدردشة (Chat Room Screen)
- **الهيدر**: معلومات العميل ورقم هاتفه والجهاز المتصل، أزرار سريعة للتحويل والإنهاء.
- **بانر الرسالة المثبتة (Pinned Message)**: إمكانية تثبيت رسالة لمدة محددة (24 ساعة، 7 أيام، 30 يوم) وإلغاء التثبيت في أي وقت.
- **بانر المحادثة المحولة**: تنبيه الموظف في حال تم تحويل المحادثة إليه من زميل.
- **منطقة الرسائل**: فقاعات واردة وصادرة بنمط واتساب الدقيق، التوقيت، علامات الصحين الأزرقين، دعم الصور والرسائل الصوتية.
- **خيارات الرسالة (الضغط المطول)**: الرد، التثبيت، التمييز بنجمة ⭐، نسخ النص، الحذف.
- **شريط الإدخال المدمج**:
  - حقل كتابة مريح
  - زر الردود السريعة الجاهزة (Quick Replies)
  - زر إرسال الصور والمرفقات
  - زر الإرسال الأخضر الدائري

### 4. النوافذ المنبثقة التفاعلية (Modals)
- **محادثة جديدة (New Chat Modal)**: إدخال رقم الهاتف واختيار الجهاز وإرسال أول رسالة.
- **الردود السريعة (Quick Replies Modal)**: استعراض واختيار الردود السريعة بنقرة واحدة.
- **تحويل المحادثة (Transfer Modal)**: اختيار الزميل من قائمة الموظفين وإضافة ملاحظة توضيحية.
- **إنهاء المحادثة (Resolve Modal)**: تقييم المحادثة بنجوم (1-5) وكتابة ملخص الإغلاق.
- **مدة التثبيت (Pin Duration Modal)**: تحديد مدة تثبيت الرسالة بنمط واتساب.

## 🚀 كيفية التشغيل والتطوير

### المتطلبات
- Node.js (v18+)
- Expo CLI

### تشغيل التطبيق في وضع التطوير
```bash
cd mobile
npx expo start
```
- يمكنك مسح رمز الـ QR عبر تطبيق **Expo Go** على هاتفك (Android أو iOS).
- أو الضغط على `a` لتشغيل محاكي Android.
- أو الضغط على `i` لتشغيل محاكي iOS.
- أو الضغط على `w` لمعاينة نسخة الويب.

### فحص الكود والأنواع
```bash
npx tsc --noEmit
npx expo-doctor
```

### بناء تطبيق Android APK / Bundle (عبر EAS)
```bash
npx eas-cli build -p android --profile preview
```
